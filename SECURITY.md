# Security policy

Jump in the Mix is an early single-user, self-hosted release candidate. Only the latest tagged release candidate and the current `main` branch receive security fixes. No hosted service, external provider, or commercial support commitment is implied.

## Report a vulnerability privately

Use the repository Security tab's **Report a vulnerability** option when it is available. Include the affected version, impact, minimal reproduction steps, and a safe way to contact you.

Do not include credentials, private Contact information, relationship notes, database dumps, backup archives, encryption keys, session tokens, or a working exploit in a public issue. If private vulnerability reporting is unavailable, open a minimal public issue asking the maintainer to establish a private channel; include no sensitive details.

The maintainer will acknowledge a usable report when capacity permits, investigate it, and coordinate a fix and disclosure. This pilot project does not promise a specific response or remediation deadline.

## Operator responsibilities

Pilot operators are responsible for unique secrets, host and Docker updates, access control, encrypted backups, restore testing, and limiting network exposure. The active product has no support commitment for payment, Google, external AI, team, or other provider integrations.
