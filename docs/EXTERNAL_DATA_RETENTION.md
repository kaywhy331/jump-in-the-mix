# External data and recovery retention

This inventory complements [database retention](DATA_RETENTION.md). It records the production setup and the evidence still needed from its actual accounts. The canonical Render service, Resend sender, ImprovMX/Gmail forwarding and independent AWS recovery storage are configured; a provider API setting is distinct from an inbox or deletion receipt. Application deletion is not a provider-wide deletion receipt. Do not publish an unconditional promise that account deletion immediately erases backups, delivered messages or provider logs.

## Handling a deletion request

Verify the requester through the existing account or verified email workflow before disclosing records. Record the scope and request date in the restricted support process. Complete the applicable in-app deletion/export and retain its minimal audit identifier. Determine whether the request also concerns provider-held messages, external logs, backup copies or a customer-controlled mailbox/export.

For each applicable external location, record the responsible account, provider request/reference, normal expiry and any stated exception. Track confirmation or expiry separately from the database result. Never mark all copies deleted because a provider API accepted a request or because a storage object disappeared from the default listing. Recheck versioned/replicated storage and keep unreconciled historical restores isolated. A source that is unavailable with no independent current safety/history evidence remains a recovery roadblock; the release command cannot invent missing history.

The public notice must describe the selected, verified retention windows and actual operator/contact route. The [FTC's business guidance](https://www.ftc.gov/business-guidance/resources/protecting-personal-information-guide-business) recommends inventorying where personal information goes, limiting retention to its purpose, and defining access and disposal procedures. This document implements that inventory step; it does not establish legal compliance for an unspecified business or market.
