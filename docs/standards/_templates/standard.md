## 1. Purpose and scope

## 2. Rules

Rules are numbered paragraphs so they can be cited as `JITM-NN §2.N`. Each rule:

- uses MUST, SHOULD or MAY;
- lives in exactly one standard (other standards link to it rather than restating it);
- ends with at least one basis tag:
  - `[OWNER <date> <reference>]` — an owner decision, with where it is recorded;
  - `[SHIPPED <sha> <path>]` — current behavior verified in the code;
  - `[SOURCE <path>:<line>]` — an existing document;
  - `[PROPOSED]` — the author's recommendation, provisional until the owner confirms it.

  Line numbers in SOURCE and OWNER tags, and in other `path:line` references, refer to the source file as it stood when the rule was written: `origin/main` 9439fd6 for every 1.0.0 rule (read them with `git show 9439fd6:<path>`). Amendments and new standards name their base commit in the changelog line. SHIPPED tags name their commit.
