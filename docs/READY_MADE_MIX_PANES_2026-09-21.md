# Ready-made Mix workspace

Ready-made now shares the My mixes directory, Beat preview and context pane structure. This implements the owner's request to keep both collections visually consistent with Contacts and the supplied design export. The original export is preserved. This is an adaptation of its existing Mix workspace, not a separate catalog design.

The left pane holds the My mixes/Ready-made tabs, search, filter sheet, personal favorites and a paginated directory. Selecting a Mix updates its actual Beat names, timing, channels and wording in the center. The right pane shows setup, start conditions, goal, audience, timing, channels, approach guidance where available, and up to five non-archived copies in the current workspace. No activity or performance metrics are invented for templates.

Use this mix opens the existing guided setup with its existing draft/activation safeguards. Both Cancel and Mix library return to the selected preview. Previewing and favoriting do not copy or activate a Mix. Existing search semantics, featured ordering, tenant/user-scoped favorites and approved-only visibility are retained. Invalid template content shows an unavailable notice and does not offer setup.

Responsive behavior inherits My mixes: panes switch with Mixes/Beats/Details controls below 1200px, context follows the center from 1200px, and three columns appear at 1700px. The directory uses 20 items per page with complete pagination. The center includes a setup link when the right pane is below or hidden. Interface and wording fonts, semantic tokens, icons, both themes and flat dividers are shared with the redesigned workspace.
